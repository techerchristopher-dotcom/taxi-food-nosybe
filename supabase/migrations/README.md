# Migrations

⚠️ **Ce dossier n'est PAS l'historique complet.** Les migrations du projet ont
toutes été appliquées par le connecteur MCP Supabase, directement sur la base
de production, sans passer par le dépôt. L'historique réel est celui du
tableau de bord Supabase (`supabase_migrations.schema_migrations`).

Ce dossier a été ouvert le 2026-08-24 pour arrêter l'hémorragie : à partir
d'ici, **toute migration appliquée par MCP est aussi déposée ici**, sous le
même nom. Le but n'est pas de rejouer le dossier — c'est de pouvoir relire ce
qu'une table ou une RPC fait, sans ouvrir le tableau de bord.
